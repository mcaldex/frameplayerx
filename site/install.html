Install

FramePlayerX is free. Each way below installs the latest release and adds it to your Steam library. Developer Mode is needed only to install from a PC.

No PC needed

On the headset

  1. In Desktop Mode, open this page in the headset's browser.
  2. Download the installer.
    Download installer
  3. Open Install-FramePlayerX.desktop from your Downloads folder and confirm that you trust it.

A terminal window installs FramePlayerX and may ask to close Steam for a moment. The app then shows up in Gaming Mode.

Then start it from your Steam library. Browse the headset and its cards under On this device, and add a folder library or a media server under Sources › Add source.

To update, open Settings › Updates, press Download and install when a new version is listed, then Restart now.

Betas and installing a zip by hand are under Install in the user guide, and removing it under Uninstall.

From a PC with Frame Control

  1. Turn on Developer Mode on the headset: Steam Settings › System › Developer Mode.
  2. Pair the headset once with Frame Control on your PC.
  3. Press the button in your PC's browser.
    Install with Frame Control

From a PC's terminal

  1. Turn on Developer Mode, and download frameplayerx-install for your PC from the latest release.
  2. On the headset, open Steam Settings › Developer › Pair new host and keep it showing. Then pair once, with the headset's IP address: 
    frameplayerx-install pair 192.168.0.68
  3. Install the latest release: 
    frameplayerx-install
